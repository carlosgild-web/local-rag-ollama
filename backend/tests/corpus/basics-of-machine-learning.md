# Basics of Machine Learning

Machine learning is a way of building systems that improve at a task by
learning patterns from data, rather than following rules written by hand.

## Supervised Learning

In supervised learning, a model is trained on examples that already have
the correct answer attached, such as photos labeled "cat" or "dog". The
model learns to predict the label for new, unseen examples.

## Unsupervised Learning

Unsupervised learning works with data that has no labels. The goal is
usually to find structure, such as grouping similar items together or
reducing the data to a simpler representation.

## Evaluation

Regardless of the approach, a model's usefulness is judged by testing it
on data it has not seen during training, to check whether it generalizes
rather than simply memorizing the training examples.
