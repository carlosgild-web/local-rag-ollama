# Fundamentos del Aprendizaje Automático

El aprendizaje automático es una forma de construir sistemas que mejoran
en una tarea aprendiendo patrones a partir de datos, en lugar de seguir
reglas escritas a mano.

## Aprendizaje Supervisado

En el aprendizaje supervisado, un modelo se entrena con ejemplos que ya
tienen la respuesta correcta asociada, como fotos etiquetadas "gato" o
"perro". El modelo aprende a predecir la etiqueta de ejemplos nuevos que
no ha visto antes.

## Aprendizaje No Supervisado

El aprendizaje no supervisado trabaja con datos que no tienen etiquetas.
El objetivo suele ser encontrar estructura, como agrupar elementos
similares o reducir los datos a una representación más simple.

## Evaluación

Sin importar el enfoque, la utilidad de un modelo se juzga probándolo
con datos que no ha visto durante el entrenamiento, para comprobar si
generaliza en lugar de simplemente memorizar los ejemplos de
entrenamiento.
