# Test corpus

28 short documents written for this project, used to exercise ingestion,
chunking, and retrieval. No copyrighted or personal material — all text
here was authored for this repo and may be freely used and redistributed
under the project's license.

- 12 English, 12 Spanish, covering the same 12 topics so retrieval can be
  compared across languages against a multilingual embedding model.
- 6 topics per language as Markdown (`.md`) with heading structure, to
  test the structure-aware chunker; 6 as plain prose (`.txt`).
- A 13th topic as a `.docx` pair (`home-network-setup.docx` /
  `configuracion-red-hogar.docx`), with heading styles, to test the
  python-docx parser.
- A 14th topic as a `.pdf` pair: `energy-saving-tips.pdf` has a normal
  selectable text layer; `consejos-ahorro-energia-scanned.pdf` is a
  text-free, image-only page that forces the low-text-yield OCR fallback
  (Tesseract, `eng+spa`). Both generated by `generate_extra.py`.
